# Programación II

**Autor:** Dereck Mera

Repositorio centralizado para el almacenamiento, organización y gestión de código fuente, prácticas y proyectos desarrollados en la asignatura de **Programación II**.

El contenido está orientado al desarrollo de software backend y empresarial, estructurado en torno a tres pilares tecnológicos: Python, Django y Odoo ERP.

---

## 🐍 Python

Constituye la base lógica del repositorio y se enfoca en los siguientes aspectos:

- **Programación Orientada a Objetos (POO):** implementación de clases, herencia, polimorfismo y encapsulamiento.
- **Manejo de excepciones:** control de errores, lectura y escritura de archivos, y manipulación de estructuras de datos.
- **Buenas prácticas de programación:** desarrollo de código limpio, organizado y modular, siguiendo las convenciones de estilo establecidas en PEP 8.

## 🌐 Django

Framework web de alto nivel que permite desarrollar aplicaciones web de manera ágil, segura y estructurada.

Sus principales contenidos incluyen:

- **Arquitectura MVT (Modelo - Vista - Plantilla):** organización de los componentes de una aplicación web.
- **Gestión de bases de datos:** utilización del ORM de Django para la creación de modelos, migraciones y consultas.
- **Desarrollo de vistas:** implementación de vistas basadas en funciones y clases.
- **Formularios y autenticación:** gestión de formularios, usuarios, autenticación y sesiones.
- **Enrutamiento y plantillas:** configuración de rutas URL y renderizado de plantillas dinámicas.

## 🏢 Odoo ERP

Plataforma de gestión empresarial orientada al desarrollo e implementación de soluciones mediante módulos personalizados.

Los principales aspectos abordados son:

- **Desarrollo modular:** creación y estructuración de módulos personalizados (Addons).
- **Modelado de datos:** gestión de información mediante PostgreSQL y el ORM de Odoo (`models.Model`).
- **Campos relacionales:** implementación de relaciones `Many2one`, `One2many` y `Many2many`.
- **Lógica de negocio:** utilización de decoradores como `@api.depends`, `@api.onchange` y `@api.constrains`.
- **Interfaces de usuario:** construcción de vistas de lista, formulario y búsqueda, así como la configuración de menús mediante archivos XML.

---

## 🛠️ Entorno de trabajo

- **Lenguaje de programación:** Python 3.x.
- **Sistemas de gestión de bases de datos:** SQLite para el desarrollo local con Django y PostgreSQL para Odoo y entornos de producción.
- **Gestión de dependencias:** utilización de entornos virtuales independientes (`venv`) para aislar y administrar las dependencias de cada proyecto.

---

**Objetivo del repositorio:** documentar el proceso de aprendizaje, almacenar las prácticas académicas y organizar los proyectos desarrollados durante la asignatura de Programación II.
